# 3-minute hackathon demo
**0:00–0:25 — Problem:** Rural pregnant women may describe symptoms in natural Bangla, while access to timely triage/referral can be difficult.

**0:25–0:55 — Voice:** Open মাতৃকণ্ঠ, record or type a synthetic example: “আমার মাথা ব্যথা, চোখে ঝাপসা দেখি।” Show transcript confirmation.

**0:55–1:25 — Extraction:** Explain that the language model extracts only reported facts into structured fields; the fallback works without an API.

**1:25–1:55 — Safety engine:** Show HIGH result for headache + blurred vision. Emphasize that Python rules—not the LLM—set the risk level.

**1:55–2:20 — Action:** Show short Bangla emergency guidance and a clearly marked simulated referral SMS draft. State that nothing is transmitted.

**2:20–2:45 — Records:** Save a synthetic case and show dashboard/CSV export.

**2:45–3:00 — Limitations:** Explain that this is a screening prototype, not a diagnosis or clinically validated tool; qualified clinical review and real referral integration are prerequisites.
